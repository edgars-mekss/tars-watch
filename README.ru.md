Маленький робот-персонаж на запястье. Нажимаете на экран и говорите, он отвечает вслух. Светящиеся глаза показывают, что он делает: слушает, думает, говорит или реагирует эмоцией.

Робот играет **ТАРСа** из «Интерстеллара»: немногословного, невозмутимого военного робота. Как в фильме, у его характера есть настройки в процентах. Скажите «ТАРС, юмор 60%». Он подтвердит, сменит манеру речи, а на экране часов появится новое значение.

Приложения для Apple Watch собираются только в Xcode на Mac. Поэтому дизайн, анимации, характер и логика разговора сначала отрабатываются в браузере, в рамке 368×448, как у экрана Apple Watch Series 5 (44 мм). Всё это переносится в приложение для часов.

## Что умеет

- **Анимированное лицо.** Два светящихся глаза на SVG. Робот моргает и смотрит по сторонам, когда слушает, глаза расширяются, когда думает, взгляд ходит из стороны в сторону. Пять полосок под глазами реагируют на ваш голос, пока робот слушает, и двигаются в такт его словам, пока он говорит.
- **Эмоции.** К ответу прилагается эмоция (спокойствие, тревога, радость, растерянность, грусть). Она видна по форме век и цвету.
- **Голосовой ввод.** Браузер записывает фразу и сам определяет её конец по 1,2 с тишины. Сервер отправляет запись в Whisper (`whisper-large-v3-turbo`) и получает текст примерно за 0,7 с.
- **Озвучка.** Мужской русский голос [Piper](https://github.com/rhasspy/piper) (Дмитрий, Денис или Руслан). Речь синтезируется на сервере локально, примерно за 0,6 с. Полоски под глазами следуют за настоящей громкостью речи. Сервер превращает его в голос робота: ровная интонация плюс металлический призвук, кольцевая модуляция или огрубление звука «старого компьютера» (`robotize.js`). Если Piper не установлен, говорит голос браузера.
- **Настройки характера.** Юмор, сарказм и честность (по умолчанию 0 / 0 / 90%). Меняются голосом и сохраняются до конца разговора.
- **Короткие ответы, рассчитанные на часы.** Одно-два предложения, только устная речь, без выдуманных данных: датчиков и интернета у робота нет, поэтому про погоду или пульс он честно говорит, что данных нет.
- **Пульт отладки.** Текстовый ввод вместо голоса, выбор голоса и его высоты, просмотр всех состояний и эмоций.

## Как устроен

```
касание ─► СЛУШАЕТ ──────────► ДУМАЕТ ──────────────────────► ГОВОРИТ ─► ЖДЁТ
           запись с микрофона   /api/transcribe → Whisper       озвучка    моргает,
           (полоски реагируют)  /api/chat → модель → JSON                  смотрит по сторонам
```

Языковая модель возвращает не просто текст, а структуру:

```json
{ "reply": "Юмор установлен на шестьдесят процентов.", "emotion": "neutral", "humor": 60, "sarcasm": 0, "honesty": 90 }
```

Один ответ управляет сразу голосом, лицом и табло настроек.

| Файл | Что делает |
|---|---|
| `persona.js` | Характер: системный промпт, настройки по умолчанию, схема ответа. Всё в одном месте, чтобы перенести в приложение для часов без изменений. |
| `server.js` | Небольшой сервер на Node.js без фреймворков. Отдаёт прототип и проксирует распознавание речи и разговор, чтобы ключ API не попадал в браузер. |
| `robotize.js` | Эффекты «голос робота» для синтезированной речи: металлический призвук, кольцевая модуляция, огрубление звука. |
| `public/face.js` | Лицо: глаза, веки, эмоции, моргание, полоски голоса. |
| `public/voice.js` | Запись с микрофона с определением тишины и воспроизведение речи с замером громкости. |
| `public/app.js` | Состояния (выключен → ждёт → слушает → думает → говорит), касания, пульт отладки. |

## Решения и замеры

- **Бесплатная открытая модель в облаке, а не на часах.** У Series 5 около 1 ГБ памяти и нет нейросопроцессора. Даже модель на 0,5 млрд параметров выдавала бы примерно по слову в секунду и быстро сажала бы батарею. Поэтому на часах только лицо, микрофон и звук, а «мозг» в облаке.
- **Модель выбрана по тестам.** На одних и тех же вопросах `qwen3.8-27b` ошибался в русском, а `gpt-oss-120b` отвечал грамотно и держал характер. Сейчас используется `openai/gpt-oss-120b` на бесплатном тарифе Groq с короткими рассуждениями. Ответ приходит за 0,3–0,9 с.
- **Рассчитано на лимиты бесплатного тарифа.** Бесплатно даётся 8000 токенов в минуту, а один запрос стоит около 1,2–1,7 тыс. токенов. Поэтому модели уходят только последние 16 сообщений, а длина ответа ограничена. Если сервис упёрся в лимит, сервер ждёт несколько секунд и повторяет запрос, а не выдаёт ошибку.
- **Провайдер меняется без правки кода.** Подходит любой OpenAI-совместимый API (Groq, OpenRouter, Mistral, локальная Ollama), достаточно поменять `.env`. Claude поддерживается как платный вариант.
- **Whisper вместо распознавания речи браузера.** Работает в любом браузере, а не только в Chrome и Edge. Так же речь будет распознаваться и на часах.
- **Фильтр «галлюцинаций» Whisper.** На тишине Whisper любит «слышать» титры из видео, такие фразы отбрасываются.

## Запуск

Нужен Node.js 21.7+ и бесплатный [ключ Groq](https://console.groq.com/keys).

```bash
npm install
cp .env.example .env   # затем впишите ключ в LLM_API_KEY=
npm start              # http://localhost:3000
```

Для мужского голоса укажите в `.env` пути `PIPER_EXE` и `PIPER_VOICES`: к `piper.exe` и к папке с `ru_RU-dmitri-medium.onnx` (и/или `denis`, `ruslan`) из [релизов Piper](https://github.com/rhasspy/piper/releases) и [голосов](https://huggingface.co/rhasspy/piper-voices).

Нажмите на экран часов, чтобы включить ТАРСа, затем нажмите ещё раз и говорите. Пробел тоже работает.

### С телефона

Браузер телефона даёт доступ к микрофону только по HTTPS, поэтому сервер дополнительно работает на порту 3443 с самоподписанным сертификатом.

```bash
npm run cert   # выпускает certs/cert.pem для IP компьютера в Wi-Fi (повторить, если IP сменился)
npm start      # покажет адрес https://<ваш-ip>:3443
```

Откройте этот адрес на телефоне в той же сети Wi-Fi и примите предупреждение о сертификате. На iPhone можно установить сертификат, чтобы предупреждения не было: откройте `https://<ваш-ip>:3443/tars.crt`, установите профиль и включите его в *Настройки → Основные → Об этом устройстве → Доверие сертификатам*.

### На сервере

Прототип работает на небольшом VPS (2 ядра, Ubuntu 24.04) рядом с другими службами:

- служба systemd `tars` под отдельным пользователем, слушает только `127.0.0.1`, ограничение памяти 500 МБ;
- перед ней [Caddy](https://caddyserver.com) с автоматическим сертификатом Let's Encrypt;
- вход по секретной ссылке: `ACCESS_TOKEN` в `.env`, первый вход `/?key=…`, дальше cookie; будущее приложение для часов шлёт `Authorization: Bearer …`. Без этого посторонние израсходовали бы бесплатный лимит API.

Замеры через интернет: распознавание ~0,7 с, ответ модели ~0,5 с, голос ~1 с.
